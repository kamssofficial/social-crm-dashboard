# social-crm-dashboard

A unified CRM and official dashboard for social media operations. This project includes:

- centralized social account overview
- inbox and conversation center
- lead tracking and pipeline management
- campaigns and content scheduling
- quick action controls for team operators
- sleek admin dashboard UI for brand teams

## Features

- Multi-platform social account monitoring
- Unified inbox for comments, DMs, and leads
- Lead advancement flow and pipeline tracking
- Campaign performance cards and queue management
- Prepared dashboard structure for real platform integrations (Instagram, Facebook, X, TikTok, LinkedIn, WhatsApp)

## Tech stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes

This initial build is a polished front-end dashboard ready for extension with live OAuth and API integrations.
